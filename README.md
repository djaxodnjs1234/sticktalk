# 🍁 입에 붙는 영어 (Stick Talk)

**외운 표현이 회화에서 바로 나오게.** 원어민 회화에서 자주 쓰는 단어와 숙어를 간격 반복(SRS)으로 확실하게 외우는 모바일 웹앱입니다.

- 지금은 캐나다 어학연수(UVic, 2027-01-04 ~ 01-29) 대비 **단어 300개 + 숙어·표현 200개 = 500개**가 들어 있습니다.
- `words.js`에 항목을 추가하면 그대로 늘어납니다(4장 참고).
- 빌드 도구 없이 정적 파일만으로 동작합니다. 홈 화면에 추가하면 앱처럼 쓸 수 있고 오프라인에서도 학습할 수 있습니다.

## 1. 설계 요약

### 화면 구성 (하단 탭바)
| 탭 | 내용 |
|---|---|
| 🏠 홈 | D-day(“UVic 수업 시작까지 D-N”, 시작 후 “연수 N일차”), 오늘 목표 링(새 항목·복습), 시작 버튼, 🔥 연속 학습, 레벨·XP, 전체 진도(학습함/외움/남음), 최근 4주 히트맵 |
| 📚 학습 | 오늘의 새 항목, 상황별 학습(홈스테이·수업·카페·식당·교통·쇼핑·친구·일반), 다음에 배울 항목 |
| 🔁 복습 | 오늘 복습(SRS), 오답 노트, 자유 연습·즐겨찾기 연습, Leitner 상자 현황 |
| 📖 단어장 | 검색, 상태 필터(새 항목/학습 중/외움/⭐), 종류·상황 필터, 상세 보기 |
| ⚙️ 설정 | 하루 새 항목(10/15/20/30), 효과음·볼륨·음성 자동 재생·진동, 효과음 미리 듣기, 진도 내보내기/가져오기, 정보·라이선스 |

학습 방식 5가지: 🃏 플래시카드(오른쪽 스와이프 = 알아요, 왼쪽 = 몰라요) · 뜻 고르기 · 🎧 듣고 고르기 · 한→영 고르기 · ✍️ 빈칸 채우기 + 🎲 섞어서.
오답 선택지는 **같은 종류(단어/표현)이면서 빈도 순위가 가까운 항목**에서 뽑습니다.

### 데이터 구조 (`words.js`)
```js
{ "id": 1, "rank": 1, "type": "word", "en": "actually", "pos": "adverb", "ipa": "/ˈæktʃuəli/",
  "ko": "사실은, 실은", "example_en": "Actually, I'm from Korea, not Japan.",
  "example_ko": "사실 저는 일본이 아니라 한국에서 왔어요.", "situation": "일반", "tip": "..." }
```
진도는 `localStorage`에 항목 `id` 기준으로 저장됩니다. 상자, 다음 복습일, 정답·오답 수, 일별 기록, XP, 스트릭, 오답 노트, 즐겨찾기, 설정이 들어갑니다.

### SRS 규칙 (Leitner 5단계)
- 새 항목을 처음 학습하면 **상자 1**에 들어가고 내일 복습합니다.
- 복습일이 된 항목은 **맞히면 다음 상자로** 갑니다. 간격은 1일 → 3일 → 7일 → 14일 → 30일입니다.
- **틀리면 상자 1**로 돌아가 내일 다시 나옵니다. 틀린 항목은 세션 뒤쪽에 한 번 더 나오고 오답 노트에도 저장됩니다.
- **상자 4 이상이면 "외움"**입니다. 7일 뒤 복습까지 통과했다는 뜻입니다. 기준은 `app.js`의 `CONFIG.MASTERED_BOX`에서 바꿀 수 있습니다.
- 오답 노트 복습에서 맞히면 그 항목은 노트에서 빠집니다.
- 일일 목표는 새 항목 20개(설정에서 변경 가능)와 그날 복습할 항목 전부입니다. 500 ÷ 20 = 25일입니다.

### 원어민 음성 찾는 순서 (사람 녹음만, TTS 없음)
| 종류 | 1순위 | 2순위 | 3순위 | 없으면 |
|---|---|---|---|---|
| 단어 | Free Dictionary API `phonetics[].audio` (US → CA → UK → AU → 기타) | Wikimedia Commons `File:En-us/ca/uk/au-{단어}.ogg` (MP3 변환본) | Lingua Libre 사람 녹음 | “원어민 음성 없음” + YouGlish |
| 숙어 | Tatoeba 사람 녹음 예문 (그 표현이 들어간 짧은 문장) | 한 단어 표현이면 단어 경로 | – | “원어민 음성 없음” + YouGlish |

- 찾은 음성 주소는 `localStorage`에, 들은 음성 파일은 Cache Storage에 저장합니다. 그래서 다음에는 바로 재생되고 오프라인에서도 들을 수 있습니다.
- 재생 버튼 옆에 출처 배지가 붙습니다(예: `🎙 원어민 · US · Wiktionary`). 0.75배속 버튼도 있습니다.
- 참고: 2026-11 점검 당시 Free Dictionary API의 음성 파일 서버가 404를 돌려주고 있었습니다. 그래도 앱이 같은 녹음 원본인 Wikimedia Commons에서 자동으로 찾아 재생합니다.

## 3. 폰에서 쓰는 방법

> ⚠️ 음성(사전·Wikimedia·Tatoeba)은 **배포한 https 주소에서** 테스트하세요. 채팅 미리보기나 파일을 직접 여는 경우(`file://`)에는 외부 음성 요청과 오프라인 기능이 막힐 수 있습니다.

### 방법 A. Netlify Drop (가장 쉬움, 5분)
1. PC에서 https://app.netlify.com/drop 에 접속합니다. 무료 계정으로 로그인하세요. 로그인하지 않고 올린 사이트는 잠시 뒤 삭제됩니다.
2. 이 폴더(`sticktalk`)를 통째로 브라우저 창에 끌어다 놓습니다.
3. 몇 초 뒤 `https://무작위이름.netlify.app` 주소가 생깁니다. Site settings에서 이름을 바꿀 수 있습니다(예: `sticktalk.netlify.app`).
4. 그 주소를 폰으로 보내서 엽니다.

### 방법 B. GitHub Pages (무료, 계속 유지)
1. GitHub에 로그인한 뒤 **New repository**를 누르고, 이름을 `sticktalk`로 정하고 **Public**으로 만듭니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고 폴더 안의 파일을 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다. `icons` 폴더도 포함해야 합니다.
3. **Settings → Pages**에서 *Source: Deploy from a branch*, *Branch: main / (root)*를 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://내아이디.github.io/sticktalk/` 주소로 열립니다.

터미널을 쓴다면 이렇게 올릴 수도 있습니다.
```bash
cd sticktalk
git init && git add . && git commit -m "입에 붙는 영어 (Stick Talk)"
git branch -M main
git remote add origin https://github.com/내아이디/sticktalk.git
git push -u origin main
```

### 아이폰: 홈 화면에 추가
1. **Safari**로 배포 주소를 엽니다.
2. 아래쪽 **공유 버튼(□↑)**을 누르고 **홈 화면에 추가**를 고른 뒤 **추가**를 누릅니다.
3. 홈 화면의 **Stick Talk** 아이콘(빨간 바탕의 말풍선 🍁)으로 실행하면 주소창 없이 앱처럼 열립니다.
4. 아이폰이 **무음 모드**면 효과음이 들리지 않을 수 있습니다. 원어민 음성이 안 나오면 화면을 한 번 터치한 뒤 ▶를 누르세요.

### 안드로이드: 홈 화면에 추가
1. **Chrome**으로 배포 주소를 엽니다.
2. 오른쪽 위 **⋮** 메뉴에서 **홈 화면에 추가**(또는 **앱 설치**)를 누르고 **설치/추가**를 누릅니다.

### 오프라인으로 쓰기
- **처음 한 번은 인터넷이 연결된 상태에서** 열어야 앱 파일이 저장됩니다. 그 뒤로는 비행기 모드에서도 학습할 수 있습니다.
- 원어민 음성은 **한 번 들은 것만** 오프라인에서 재생됩니다. 출국 전에 와이파이에서 미리 학습해 두면 좋습니다.

### 폰을 바꿀 때
설정에서 **⬇️ 내보내기**를 누르면 JSON 파일이 저장됩니다. 새 폰에서 **⬆️ 가져오기**로 그 파일을 고르세요.

### 앱을 수정해서 다시 올렸다면
`sw.js` 맨 위의 `VERSION` 값을 바꾸세요(예: `v1.0.1`). 그래야 폰에 저장된 옛 파일이 새 파일로 바뀝니다.

### PC에서 확인하기
```bash
cd sticktalk
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 4. 데이터 늘리기·바꿔 끼우기
- **늘리기:** `words.js` 맨 아래에 같은 형식으로 `window.WORDS.push( {...}, {...} );` 묶음을 추가합니다. `id`는 501, 502…처럼 이어 붙이세요. 전체 개수, 진도, 단어장은 자동으로 늘어납니다. 올린 뒤에는 `sw.js`의 `VERSION`을 올려 주세요.
- **바꾸기:** `words.js`의 형식(위 데이터 구조)만 맞추면 다른 단어장으로 바꿀 수 있습니다.
- `id`는 진도 저장 키이므로 **한 번 정하면 바꾸지 마세요.** `rank`가 작은 항목부터 배웁니다.
- `situation` 값은 `홈스테이 / 수업 / 카페·식당 / 교통 / 쇼핑 / 친구 / 일반` 중 하나입니다.
- 빈칸 채우기 문제를 내려면 `example_en` 안에 `en`이 그대로 들어 있어야 합니다(-s, -ed, -ing 같은 간단한 활용형도 인식). 찾지 못하면 그 항목은 다른 문제 방식으로 나옵니다.
- D-day 날짜, 복습 간격, "외움" 기준, XP는 `app.js` 맨 위 `CONFIG`에서 바꿉니다.

## 6. 출처·라이선스
- 단어 발음: Wiktionary / Wikimedia Commons 녹음(CC BY-SA, 녹음자 정보는 각 파일 페이지), Lingua Libre(CC BY-SA)
- 사전 조회: Free Dictionary API (dictionaryapi.dev)
- 숙어 예문 음성: Tatoeba. 문장은 CC BY 2.0 FR이고, 음성은 녹음자마다 라이선스가 다릅니다(CC BY, CC BY-NC-ND 등). 앱에서 재생할 때 녹음자 이름을 표시합니다.
- 영상 발음: YouGlish(외부 링크)
- 학습 데이터(뜻·예문·팁)는 이 앱을 위해 작성했습니다. 개인 학습용입니다.
